# Othmane

Projet web moderne avec système de connexion simple.

## Structure
- `index.html` : Page d'accueil
- `login.html` : Page de connexion
- `home.html` : Tableau de bord (accessible après login)
- `About.html` : À propos
- `Contact.html` : Contact
- `index.css` : Styles premium
- `login.js` : Logique de connexion
- `index.js` : Scripts globaux

## Utilisation
Ouvrez `index.html` dans un navigateur.
Identifiants par défaut :
- Utilisateur : `admin`
- Mot de passe : `admin`
